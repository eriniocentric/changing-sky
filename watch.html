Watch one object change

Three objects Rubin keeps seeing change, June–November 2026. Each flip-book shows Rubin's own image stamps (8″ across) for every alert: Rubin now (the new exposure), Reference (the deep "before" image), and Difference (now minus before: red = brighter, blue = fainter). Frames are rotated to north-up, east-left and shown on one fixed brightness scale per object, so changes are real changes. Data: Fink broker public API; context images: Legacy Surveys DR11. A Changing Sky demo, not an official Rubin product.
